Two-Part Connectors

Goal: I can compare, weigh options, and structure an argument using je … desto, sowohl … als auch, weder … noch, and the other two-part connectors that carry most structured German argument.

Two sentences that weigh something

    Step 2 · Understand

    Seven pairs, three jobs

    You already know single connectors like obwohl and trotzdem (B1 Unit 3). These come in pairs.

    Comparing: je … desto. The trickiest word order here: je opens a verb-final clause, desto (or umso) opens the second — and counts as position 1, so the comparative and verb both follow it directly: Je mehr man übt, desto sicherer wird man.

    Parallel pairs: sowohl … als auch / weder … noch. Both join two equal elements — sowohl … als auch says both are true, weder … noch says neither is. Never add an extra nicht with weder … noch — that would double the negative.

    Asymmetrical pairs: nicht nur …, sondern auch / entweder … oder. nicht nur … sondern auch flags the second element as a noteworthy addition, not just an equal partner. entweder in position 1 inverts the first clause, the way any adverb opening a sentence does.

    Conceding and weighing: zwar …, aber / einerseits …, andererseits. zwar … aber concedes a point before contradicting it; einerseits … andererseits is the standard essay frame for laying out both sides before drawing a conclusion.

    One more: je nachdem. Related to je … desto but different — it means "depending on," usually followed by ob or a question word: Je nachdem, wie das Wetter wird, …

    Step 2 · Understand

    Not one rule — but not random either

    Every A1 course eventually admits it: German noun plurals don't follow one simple rule the way English -s mostly does. But "no one rule" isn't the same as "memorize every word separately" — nearly every noun's plural falls into one of a small number of recognizable patterns. Animals happen to cover all of them, which makes this unit as much a grammar reference as a vocabulary list.

    The patterns: add -e (Hund → Hunde); add -e plus an umlaut (Kuh → Kühe); add -er plus an umlaut (Huhn → Hühner); add -n or -en (Katze → Katzen, Bär → Bären); just an umlaut, no ending at all (Vogel → Vögel); no change whatsoever (Kaninchen → Kaninchen); or, for a few loanwords, add -s (Känguru → Kängurus). Seven patterns cover almost everything — recognizing which one a word follows beats memorizing each plural from scratch.

      Step 9 · Encounter again

      Where this shows up next

      Every noun you've learned so far — family members, food, drinks, furniture — already has a plural quietly following one of these same seven patterns. From here on, when a new noun's plural looks unfamiliar, try matching it to one of these patterns first before treating it as one more thing to memorize.

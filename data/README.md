# /data

Structured content (vocabulary, lessons, grammar, stories, etc.) lives here
as JSON, separate from the HTML/JS that renders it. See
`/docs/content-model.md` for the schema each content type follows.

This directory is intentionally empty until the Phase 2 content and lesson
engines land (see `/docs/roadmap.md`) — content isn't added ahead of the
code that would actually make use of it.

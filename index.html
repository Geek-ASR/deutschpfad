How Deutschpfad works

Every topic on this site — a grammar point, a set of words, a piece of history — moves through the same nine-step loop, so learning compounds instead of resetting with each new page.

  1. Discover

    Meet new words or a pattern inside a real sentence, not an isolated list.

  2. Understand

    See what it means, and why German expresses it this way.

  3. Learn the pattern

    Notice the underlying rule behind the example, not just the example itself.

  4. Practice

    Try it in a few short, low-stakes exercises before anything is scored.

  5. Retrieve

    Recall it without looking — active recall builds memory faster than rereading.

  6. Apply

    Use it to do something real: order food, ask a question, tell a story.

  7. Quiz

    Check understanding with varied question types — not endless multiple choice.

  8. Review later

    A lightweight spaced-review system brings it back before you'd forget it.

  9. Encounter again

    Meet the same word or pattern later, in a story, a scenario, or a quiz.

A path through six levels

The curriculum follows the CEFR scale from A1 to C2 — described here with plain "can-do" goals rather than jargon. Deutschpfad is not an official certification; it's a structured way to measure your own progress.

A1

Absolute beginner

  • I can introduce myself and share basic personal information.
  • I can understand simple everyday expressions and phrases.
  • I can ask and answer simple questions on familiar topics.
See A1 details
A2

Elementary

  • I can describe my daily routine and immediate surroundings.
  • I can communicate in simple, common everyday situations.
  • I can talk about my background in simple, connected terms.
See A2 details
B1

Intermediate

  • I can explain my experiences, opinions, and plans.
  • I can handle most situations while traveling in a German-speaking area.
  • I can produce simple, connected text on familiar topics.
See B1 details
B2

Upper intermediate

  • I can grasp the main ideas of complex text on concrete and abstract topics.
  • I can interact with enough fluency for regular contact with native speakers.
  • I can explain a viewpoint, weighing advantages and disadvantages.
See B2 details
C1

Advanced

  • I can understand demanding, longer texts and recognize implicit meaning.
  • I can express myself fluently without obviously searching for words.
  • I can use German flexibly for social, academic, and professional life.
See C1 details
C2

Mastery

  • I can understand virtually everything heard or read with ease.
  • I can summarize information from several spoken or written sources.
  • I can express myself spontaneously and precisely in complex situations.
See C2 details

Built for learners, not for data collection

There is no login, no tracking pixel, and no server watching what you study. Deutschpfad runs entirely as static files in your browser, and anything it remembers about your progress is saved only on your device.

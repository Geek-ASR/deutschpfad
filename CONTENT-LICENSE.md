# Content licensing

Deutschpfad separates **code** (MIT, see `LICENSE`) from **educational content**
(lessons, vocabulary, grammar notes, stories, history text, exercises).

## Original content

Unless a data file says otherwise, original content written for this project
(lesson text, exercises, explanations, example sentences) is licensed under
**Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0)**:
https://creativecommons.org/licenses/by-sa/4.0/

## Third-party and public-domain content

Some content (e.g. classic fairy tales, historical source excerpts) comes from
the public domain or from openly licensed sources. Every such item must carry
`source` and `license` fields in its data record (see `docs/content-model.md`)
so provenance is never lost. No copyrighted material is included without a
license that permits it.

## Audio

Any pronunciation or listening audio shipped with the site must be either
recorded for this project, public domain, or used under a license compatible
with free redistribution. License and attribution are tracked per file.

## Rule

If a piece of content's source or license cannot be verified, it does not go
into the repository. When in doubt, leave it out.
